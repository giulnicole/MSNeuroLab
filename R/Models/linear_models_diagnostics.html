Introduction

Linear regression is used to model the relationship between a continuous outcome and one or more predictor variables.

Before interpreting results, you should check the following assumptions:

  1. Linearity: Relationship between predictors and outcome is linear.
  2. Normality of residuals: Residuals are normally distributed.
  3. Homoscedasticity: Constant variance of residuals across predicted values.
  4. Independence of errors.
  5. No multicollinearity: Predictors are not highly correlated.
  6. No influential points: No single observation unduly affects the model.

Fit linear model

results_list <- list()

for (var in predictors) {
  formula <- as.formula(paste(outcome, "~", var))
  model <- lm(formula, data = data)
  
  # Model diagnostics
  par(mfrow=c(2,2))
  plot(model, main = paste("Diagnostics for", var))
  
  tidy_model <- broom::tidy(model)
  results_list[[var]] <- tidy_model
}

results_table <- bind_rows(results_list) %>%
  rename(Predictor = term)

knitr::kable(results_table, digits = 3, caption = "Linear Regression Results for Each Predictor")
